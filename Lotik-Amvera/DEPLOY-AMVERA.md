# Lotik на Amvera

Архив для Amvera разворачивается как одно приложение Docker. В одном процессе Node.js работают сайт, Mini App, Telegram webhook и фоновый парсер. SQLite доступна тому же процессу. Используйте одну реплику. Файлы для отдельного развёртывания на Ubuntu остаются в исходном проекте.

В корне загрузки должны лежать `amvera.yaml`, `Dockerfile.amvera`, файлы `*.mjs` и папка `public`. Выберите окружение **Docker**, порт контейнера **3000** и постоянное хранилище **/data**. Эти значения уже записаны в `amvera.yaml`. Lotik использует Node.js 24 и стандартный модуль `node:sqlite`. Для сборки не нужны сторонние npm- или Python-пакеты. [Настройка Docker в Amvera](https://docs.amvera.ru/applications/configuration/docker.html).

## Первый запуск

1. Создайте приложение в Amvera и загрузите содержимое архива в корень кода или отправьте его в репозиторий проекта.
2. В разделе «Переменные» установите `MODE=demo` и `PARSER_MODE=fixture`. Парсер будет работать с тестовыми карточками. Оставьте токены Telegram, платные API и настройки оплаты пустыми.
3. После развёртывания добавьте HTTPS-домен во вкладке «Домены». Откройте корень домена, проверьте `/health`, сохраните поисковую ссылку в Mini App и перезапустите приложение. Ссылка должна сохраниться, а в разделе «Репозиторий → Data» должен быть файл `demo/radar.sqlite`. [Домены Amvera](https://docs.amvera.ru/applications/configuration/network.html).

## Рабочий режим

В разделе «Переменные» задайте:

| Имя | Значение |
| --- | --- |
| `MODE` | `production` |
| `PUBLIC_URL` и `WEB_PUBLIC_URL` | HTTPS-адрес из вкладки «Домены» |
| `BOT_TOKEN` | Токен из BotFather. Добавьте как секрет |
| `WEBHOOK_SECRET` | Случайная строка длиной 32–256 символов из букв ASCII, цифр, дефиса и подчёркивания. Добавьте как секрет |
| `OWNER_TELEGRAM_ID` и `SUPPORT_CONTACT` | Telegram ID владельца и контакт поддержки |
| `PARSER_MODE` | `off` при первом запуске. После согласования доступа к Авито используйте `live` и `AVITO_ACCESS_APPROVED=1` |
| `ENABLE_CARD_CHECKOUT` | `0` |

Оставьте поля API.SH и ЮKassa пустыми. Перезапустите приложение, чтобы применить переменные. Когда `/health` отвечает по HTTPS, зарегистрируйте webhook и кнопку Mini App командой `npm run setup:telegram` на компьютере с Node.js 24. Скрипт берёт те же значения из локального `.env`; файл с секретами не загружайте в Amvera. [Переменные и секреты Amvera](https://docs.amvera.ru/applications/configuration/variables.html).

## База данных

Рабочая база находится в `/data/radar.sqlite`, а демо — в `/data/demo/radar.sqlite`. Контейнер по умолчанию использует журнал SQLite `DELETE`, поэтому не зависит от файлов общей памяти WAL. Проект рассчитан на одну реплику и доступ к SQLite с одного узла. [Постоянное хранилище Amvera](https://docs.amvera.ru/applications/storage.html), [ограничения SQLite WAL](https://www.sqlite.org/wal.html).

Если переносите существующих пользователей и поиски, запустите сначала демо, чтобы Amvera создала хранилище. На старом экземпляре остановите новые записи и сделайте согласованную резервную копию через `node parser-admin.mjs backup /путь/к/копии.sqlite` с его прежним `DATA_DIR`. Загрузите полученный снимок под именем `radar.sqlite` в корень вкладки **Data**, затем переключите приложение в рабочий режим. При замене уже работающей базы сначала остановите приложение и сохраните копию текущего файла. [Загрузка SQLite в Amvera](https://docs.amvera.ru/databases/sqlite.html).
